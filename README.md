# Sentiment Analysis with PhoBERT

This project implements a **Sentiment Analysis** system using the **PhoBERT** model for the Vietnamese language. The model classifies text into three categories: **Positive**, **Neutral**, and **Negative**. This repository provides a simple API to analyze sentiment using the pre-trained PhoBERT model from Hugging Face.

## Features

- **Sentiment Analysis**: Classify Vietnamese text into three sentiment categories using the PhoBERT model.
- **Flask API**: A Flask-based API to receive text input and return sentiment predictions.

## Requirements

To run this project, make sure you have the following libraries installed:

- Python 3.x
- Flask
- PyTorch
- Hugging Face `transformers`
